# Hypertask App Releases

Public download + update channel for the Hypertask mobile shell (`ai.hypertask.app`).

- **Latest APK:** https://github.com/valentinyeo/hypertask-app-releases/releases/latest/download/hypertask.apk
- **Version manifest:** [latest.json](latest.json) — the app checks this on launch.

Source of the shell is private. This repo only distributes signed builds.
